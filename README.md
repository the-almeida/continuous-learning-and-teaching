# continuous-learning-and-teaching
Aggregator repositoy started on 2025. Here I add all the code written while studying or teaching programming.

#### Finished:
- **crafting-a-beautiful-website:** A real client website, from briefing to approved design: moodboard, four copies × four designs, and incremental rounds until the final variation (Astro 7, TypeScript, Vitest)
- **superdoc-nextjs-playground:** Exploring SuperDoc (open source document editor) integration with Nextjs ([https://superdoc.thealmeida.online](https://superdoc.thealmeida.online/))
- **windows-x11-selection:** AutoHotkey v2 script bringing Linux/X11-style select-to-copy and middle-click paste to Windows, with a selection buffer separate from Ctrl+C
- **ai-tooling/strip-ai:** Claude Code plugin that exports a codebase as a zip with AI-assistant traces removed and PII/secrets redacted, re-running the tests to prove nothing broke

- **python-selenium-linkedin-automation:** Playground with Python fundamentals and Selenium
